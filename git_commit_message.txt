feat: Add Portfolio endpoint integration for position tracking

## Summary
Implements the Trading212 Portfolio API endpoint (/api/v0/equity/portfolio) 
to fetch all open positions with current prices, quantities, and P&L data. 
This is the foundation for implementing Time-Weighted Return (TWR) calculations.

## Changes Made

### API Layer (api/)
- **constants.js**: Added PORTFOLIO resource configuration
  - Endpoint: 'equity/portfolio'
  - Sheet: 'Portfolio'
  - Rate limit: 1 request per 5 seconds (per API spec)
  
- **fetchFunctions.js**: 
  - Created fetchPortfolio() function following existing patterns
  - Updated fetchSelectedTrading212Data() to include Portfolio mapping
  - Added comprehensive JSDoc documentation

### UI Layer (ui/)

  - Location: Trading212 Portfolio → Data → Fetch Portfolio

  - Label: "Portfolio Positions"

  - Positioned after Cash Balance

## Portfolio Data Fields
The endpoint returns the following fields per position:
- ticker: Unique instrument identifier (e.g., "AAPL_US_EQ")
- quantity: Total shares owned
- currentPrice: Current market price
- averagePrice: Average purchase price (cost basis)
- ppl: Profit/loss in account currency
- fxPpl: Forex impact (for non-account currency positions)
- initialFillDate: Date of first purchase
- maxBuy: Additional quantity that can be bought
- maxSell: Quantity that can be sold
- pieQuantity: Shares invested in pies
- frontend: Origin of purchase (API/IOS/ANDROID/WEB/SYSTEM/AUTOINVEST)

## Technical Details
- No pagination: Returns all positions in single response
- No parameters required for this endpoint
- Rate limit compliant: 1 request per 5 seconds
- Follows existing fetch pattern with automatic sheet creation
- Proper error handling and progress tracking
